# COLLECTE — SITE PREMIUM

Objectif : disposer de la matière suffisante pour adapter proprement un MASTER métier DIGIYLYFE sans transformer la collecte en interrogatoire.

## Hérite de la FICHE

Le SITE PREMIUM réutilise automatiquement :

- identité professionnelle ;
- métier / activité ;
- zone ;
- téléphone ;
- WhatsApp ;
- services principaux ;
- visuels déjà fournis ;
- présentation validée ;
- adresse / horaires / liens déjà disponibles ;
- langue source ;
- site existant lorsqu’il a été fourni.

## Complément minimum Atelier

- objectif principal du site ;
- prestation ou activité prioritaire à mettre en avant ;
- présentation suffisamment complète pour nourrir le MASTER métier ;
- détail des services ou catégories principales ;
- matière visuelle adaptée au métier ;
- appel à l’action principal : appeler, WhatsApp, réserver, demander un devis, visiter, acheter, etc. ;
- adresse / zone / horaires lorsque le métier l’exige ;
- logo / couleurs si le professionnel dispose déjà d’une identité visuelle ;
- liens sociaux utiles ;
- domaine ou souhait de domaine si nécessaire à la publication.

## Selon le MASTER métier

Demander uniquement les données propres au moule sélectionné.

Exemples :

- LOC : hébergement, capacité, équipements, conditions, photos, localisation utile ;
- BUILD / SERVICE : prestations détaillées, zones d’intervention, exemples de réalisations ;
- COMMERCE : catégories, produits mis en avant, modalités de contact ou commande ;
- RESTO : offre, carte/menu, horaires, réservation, photos ;
- DRIVER : zones, types de trajets, véhicule ou service lorsque pertinent.

Le MASTER décide des champs métier nécessaires. Le pays ne crée pas un nouveau questionnaire.

## Éléments techniques déjà portés par le MASTER

Ils ne doivent pas être redemandés au client comme s’il devait les concevoir :

- structure responsive / mobile ;
- PWA lorsque le MASTER la prévoit ;
- langues prévues par le MASTER ;
- RTL arabe ;
- contacts directs ;
- principes 0 % commission / paiement direct lorsqu’ils s’appliquent ;
- composants techniques standards du moule.

## Contrôle Atelier

- [ ] MASTER métier identifié ;
- [ ] données CARTE/FICHE récupérées sans doublon ;
- [ ] objectif du site compris ;
- [ ] contenu suffisant pour toutes les sections utiles ;
- [ ] visuels suffisants et exploitables ;
- [ ] CTA principal défini ;
- [ ] informations métier spécifiques présentes ;
- [ ] aucun tarif / horaire / garantie / certification inventé ;
- [ ] copie de travail créée depuis le MASTER, jamais depuis un site client maître ;
- [ ] validation humaine prévue avant publication.

## Sortie attendue

Un SITE PREMIUM adapté au professionnel à partir du MASTER métier correspondant, avec contenu validé, contacts directs et fonctions déjà prévues dans ce MASTER.

**Décision Atelier : si une section du MASTER n’a aucune matière réelle, on la retire ou on demande le complément ; on ne l’invente pas.**
