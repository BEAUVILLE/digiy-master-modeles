# COLLECTE — FICHE PERSONNALISÉE

Objectif : produire une fiche professionnelle plus complète qu’une carte, tout en restant légère à collecter.

## Hérite de la CARTE

La fiche reprend automatiquement les données déjà disponibles :

- identité professionnelle ;
- métier / activité ;
- zone ;
- téléphone ;
- WhatsApp ;
- services principaux ;
- visuel principal ;
- langue source.

## Complément minimum recommandé

- une présentation courte du professionnel ou de l’activité ;
- 1 à 3 visuels complémentaires lorsque l’activité gagne à être montrée ;
- adresse ou zone détaillée si utile au métier ;
- horaires si le professionnel reçoit du public ;
- lien social ou site existant si le professionnel souhaite l’afficher.

## Si le professionnel ne fournit pas de présentation

L’Atelier peut préparer une proposition courte à partir des informations déjà validées dans le dossier.

Cette proposition doit rester factuelle et doit être contrôlée avant publication.

L’Atelier ne doit jamais inventer :

- tarifs ;
- promotions ;
- diplômes ;
- certifications ;
- garanties ;
- horaires ;
- adresse ;
- disponibilité ;
- ancienneté ;
- témoignages ;
- prestations non déclarées.

## Contrôle Atelier

- [ ] base CARTE complète ;
- [ ] présentation courte disponible ou préparée pour validation ;
- [ ] photos exploitables ;
- [ ] adresse / horaires seulement s’ils sont utiles et confirmés ;
- [ ] liens directs testés ;
- [ ] aucune information commerciale inventée ;
- [ ] contenu adapté au métier.

## Sortie attendue

Une fiche personnalisée DIGIYLYFE qui présente clairement le professionnel, son activité, ses services et ses contacts directs.

**Décision Atelier : demander seulement ce qui améliore réellement la fiche.**
