# COLLECTE — SITE EXTRA

Objectif : cadrer un site enrichi ou spécifique sans perdre le contrôle du périmètre.

## Hérite du SITE PREMIUM

Le SITE EXTRA réutilise toute la matière déjà validée pour CARTE, FICHE et SITE PREMIUM.

## Complément EXTRA

Demander seulement ce qui correspond réellement au besoin supplémentaire :

- galerie photo ou vidéo plus riche ;
- contenus longs ou plusieurs univers de présentation ;
- catalogue, collections, menus, offres ou listes structurées ;
- documents à intégrer ;
- demandes de sections supplémentaires ;
- parcours utilisateur particulier ;
- fonctions spécifiques non présentes dans le MASTER standard ;
- intégrations externes réellement nécessaires ;
- besoins particuliers de réservation, demande, commande, devis ou prise de contact ;
- identité graphique plus poussée ;
- contraintes de reprise d’un site existant ;
- exigences précises de domaine, migration ou redirection lorsqu’elles font partie du périmètre accepté.

## Avant fabrication

L’Atelier doit distinguer :

### Inclus par le MASTER

Tout ce qui existe déjà dans le MASTER métier et ne nécessite qu’une adaptation de contenu ou de configuration.

### Personnalisation EXTRA

Tout ce qui nécessite une adaptation spécifique mais reste dans le périmètre accepté du site.

### Hors périmètre

Tout moteur métier, logiciel, automatisation, intégration complexe, abonnement externe ou besoin non prévu doit être identifié séparément avant fabrication.

Un SITE EXTRA ne signifie pas « tout est inclus sans limite ».

## Validation du périmètre

Avant de commencer une fonction spécifique, consigner clairement :

- besoin demandé ;
- résultat attendu ;
- contenu fourni par le client ;
- dépendance externe éventuelle ;
- validation humaine du périmètre.

## Contrôle Atelier

- [ ] base PREMIUM complète ;
- [ ] enrichissements listés ;
- [ ] contenus supplémentaires disponibles ;
- [ ] fonctions spécifiques identifiées ;
- [ ] intégrations externes identifiées ;
- [ ] périmètre validé avant développement ;
- [ ] aucun moteur métier ajouté automatiquement ;
- [ ] aucun contenu commercial inventé ;
- [ ] copie de travail séparée du MASTER MAÎTRE ;
- [ ] mobile, contacts, formulaires, langues, RTL, PWA et QR contrôlés selon le MASTER ;
- [ ] validation humaine avant publication.

## Sortie attendue

Un SITE EXTRA plus riche ou plus spécifique qu’un PREMIUM, construit à partir du même principe de MASTER métier, avec les personnalisations explicitement validées.

**Décision Atelier : l’EXTRA enrichit le site ; il n’ouvre jamais automatiquement la porte à tous les moteurs et logiciels DIGIYLYFE.**
