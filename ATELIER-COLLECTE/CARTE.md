# COLLECTE — CARTE DIGIYLYFE

Objectif : fabriquer une carte de visite numérique claire et exploitable **sans alourdir l’entrée client**.

## Minimum obligatoire

La carte peut être fabriquée dès que le dossier contient :

- nom professionnel / enseigne ;
- métier ou activité ;
- zone principale ;
- téléphone ;
- WhatsApp si utilisé par le professionnel ;
- 3 à 4 services ou activités principales ;
- au moins 1 visuel exploitable : photo professionnelle, photo d’activité ou logo ;
- langue source.

## À récupérer seulement si utile

- adresse précise ;
- horaires ;
- slogan ou phrase de présentation ;
- email ;
- réseaux sociaux ;
- site existant ;
- logo distinct de la photo principale ;
- deuxième moyen de contact ;
- QR particulier demandé par le professionnel.

## Ce qui ne doit pas bloquer

L’absence de ces éléments ne bloque pas une carte simple :

- logo ;
- réseaux sociaux ;
- horaires ;
- adresse précise ;
- longue présentation ;
- galerie photos.

## Contrôle Atelier avant fabrication

- [ ] identité professionnelle cohérente ;
- [ ] métier compréhensible ;
- [ ] zone affichable ;
- [ ] téléphone cliquable ;
- [ ] WhatsApp correct ;
- [ ] services lisibles ;
- [ ] visuel principal exploitable ;
- [ ] aucune donnée inventée ;
- [ ] aucune donnée privée non destinée à être publiée.

## Sortie attendue

Une carte de visite numérique DIGIYLYFE avec identité, métier, zone, services, visuel et contacts directs.

**Décision Atelier : si le minimum obligatoire est présent, ne pas recontacter le client inutilement.**
