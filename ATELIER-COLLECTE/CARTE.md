# COLLECTE — CARTE DIGIYLYFE

Objectif : fabriquer une carte de visite numérique claire et exploitable **sans alourdir l’entrée client**.

Moule opérationnel de référence :

`MASTER-CARTE-ADHERENT-V1/`

La carte est le socle adhérent. Elle ne doit pas être transformée automatiquement en fiche enrichie, catalogue, boutique ou site.

## Minimum obligatoire

La carte peut être fabriquée dès que le dossier contient :

- nom professionnel / enseigne ;
- métier ou activité ;
- zone principale ;
- téléphone public ;
- WhatsApp si utilisé par le professionnel ;
- 3 à 4 services ou activités principales ;
- au moins 1 visuel exploitable : photo professionnelle, photo d’activité ou logo ;
- langue source.

## À récupérer seulement si utile

- adresse précise ;
- horaires ;
- slogan ou phrase de présentation ;
- email ;
- réseaux sociaux ;
- site existant ;
- logo distinct de la photo principale ;
- deuxième moyen de contact.

## Ce qui ne doit pas bloquer

L’absence de ces éléments ne bloque pas une carte simple :

- logo ;
- réseaux sociaux ;
- horaires ;
- adresse précise ;
- longue présentation ;
- galerie photos.

## À produire par l’Atelier

Ces éléments ne sont pas à demander au client comme s’il devait les fabriquer lui-même :

- URL canonique publique, lisible et destinée à rester stable ;
- numéro technique normalisé pour `tel:` ;
- numéro WhatsApp normalisé lorsque WhatsApp est utilisé ;
- QR généré sur **l’URL canonique exacte** ;
- PWA légère issue du `MASTER-CARTE-ADHERENT-V1` ;
- signature : **DIGIYLYFE.COM · L’empreinte numérique du professionnel**.

Une fois diffusé, le QR ne doit pas être remplacé parce que l’adhérent ajoute plus tard une fiche, un catalogue, une boutique ou un site. Le contenu évolue derrière la même porte stable.

## Contrôle Atelier avant fabrication

- [ ] identité professionnelle cohérente ;
- [ ] métier compréhensible ;
- [ ] zone affichable ;
- [ ] numéro public lisible ;
- [ ] téléphone cliquable ;
- [ ] WhatsApp correct si utilisé ;
- [ ] services lisibles ;
- [ ] visuel principal exploitable ;
- [ ] aucune donnée inventée ;
- [ ] aucune donnée privée non destinée à être publiée.

## Sortie attendue

Une carte de visite numérique DIGIYLYFE comportant au minimum :

- identité, métier, zone, services et visuel ;
- numéro public affiché ;
- **Appeler** ;
- **WhatsApp** si disponible ;
- **Copier le numéro** ;
- **Partager** lorsque le navigateur le permet, avec copie du lien en secours ;
- **Garder cette carte** / ajout volontaire à l’écran d’accueil lorsque supporté ;
- QR stable relié à l’URL canonique ;
- signature DIGIYLYFE canonique.

Le scan du QR ne doit jamais être présenté comme une installation automatique de la PWA.

**Décision Atelier : si le minimum obligatoire est présent, ne pas recontacter le client inutilement.**
